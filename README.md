# 🪷 Sri Sucharitha Dhamma School & Sri Sudharma Temple

A modern, responsive, and bilingual website developed for **Sri Sucharitha Dhamma School** and **Sri Sudharma Temple**, Mawathgama, Sri Lanka.

The website is designed to provide students, parents, devotees, and the local community with easy access to information about the Dhamma School, temple, classes, teachers, events, activities, gallery, and contact details.

---

## 🌐 Project Overview

The **Sri Sucharitha Dhamma School & Sri Sudharma Temple Website** is a front-end web project focused on creating a clean, modern, accessible, and mobile-friendly digital presence for the institution.

The website supports **Sinhala and English languages** and includes modern UI features such as animations, responsive layouts, interactive galleries, video content, dark mode, and a premium loading screen.

## 🚀 Getting Started

### 1. Clone the Repository

```bash
git clone https://github.com/YOUR-USERNAME/Sri-Sucharitha-Dhamma-School-Website.git
```

### 2. Open the Project

Navigate to the project folder:

```bash
cd Sri-Sucharitha-Dhamma-School-Website
```

### 3. Run the Website

Since this is a front-end website, you can open:

```text
index.html
```

directly in a web browser.

For development, you can also use **Visual Studio Code + Live Server**.

---

## 💻 Running with VS Code

1. Open the project in **Visual Studio Code**
2. Install the **Live Server** extension
3. Right-click `index.html`
4. Select **Open with Live Server**
5. The website will open in your browser
